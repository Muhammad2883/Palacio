# 🏛️ Palacio Pyramids Hotel - Luxury Royal Menu

An elegant, interactive digital dine-in menu for **Palacio Pyramids Hotel**, overlooking the Great Pyramids of Giza. Designed with royal white & metallic gold aesthetics, responsive typography, and smooth micro-interactions.

## ✨ Key Features

- 🌓 **Dark & Light Royal Mode**: Instant theme switcher with memory persistence (`localStorage`). Sleek obsidian & gold aesthetic in dark mode.
- 🔍 **Live Instant Search**: Real-time filtering across all dishes, drinks, and descriptions with match highlighting.
- 📱 **Sticky Category Navigation**: Smooth scrolling category pills with scrollspy and thumbnail icons.
- 🖼️ **Interactive Photo Lightbox**: High-resolution dish previews with Ken Burns motion effect and zoom modal.
- 💎 **Premium Styling**: Pure white & metallic gold theme, dotted leader pricing, and custom typography (`Cinzel` & `Montserrat`).
- ⚡ **Zero-Dependency & Offline Ready**: Standalone HTML, Tailwind CSS, and Vanilla JavaScript—blazing fast with zero load time.
